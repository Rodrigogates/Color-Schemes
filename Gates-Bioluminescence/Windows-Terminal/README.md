# Bioluminescence — Windows Terminal Color Scheme

Windows Terminal port of the Bioluminescence Rider scheme, mapped to the 16 ANSI colors.
Comments/secondary text (brightBlack) use #3A6A8F, same as the IDLE port.

1. Open Windows Terminal settings (Ctrl + ,) > Open JSON file.
2. Paste the contents of `Bioluminescence.json` inside the `"schemes": [ ... ]` array.
3. Save, then pick it in your profile > Appearance > Color scheme > Bioluminescence.

Pair it with the Monocraft font to match the Rider setup.
